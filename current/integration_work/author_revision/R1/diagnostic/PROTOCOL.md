# Response-resolution diagnostic: frozen protocol

Frozen 2026-10-23T12:05Z, before any SIIE-with-HK-slices fit was run or inspected.
The three settings were chosen after the original v8 simulation study and after
reviewer diagnostics (R1); the selection is therefore not prospective. Freezing
this rerun fixes only its execution and summaries.

## Terminology

SIIE is the quantile-based SIIE-Q of Wu (2026). "SIIE (H slices)" and
"SIIE (HK slices)" are the same estimator, `siie_q()`, at two slice counts.
In the code, `siie_q(X, Y, d, S, alpha)` is `dsiie(X, Y, d, H = S, K = 1, alpha)`.
DSIIE is `dsiie(X, Y, d, H, K, alpha)`.

## Fits per replication

1. SIIE (H slices): `siie_q(X, Y, 1, H, alpha)`.
2. SIIE (HK slices): `siie_q(X, Y, 1, H*K, alpha)`; same alpha as DSIIE.
3. DSIIE: `dsiie(X, Y, 1, H, K, alpha)`.
4. Identity check only: SIR, SAVE, pHd, DR, SIME with the v8 dispatch `fit_one8()`
   (csMAVE is not refitted; its archived values are not used by the diagnostic).

Matched conventions (verified per replication, not assumed): SIIE (HK slices) and
DSIIE use the same divisor-n whitening matrix, the same order of (Y_i, i), the
same block rule `rank_split(n, HK)`, the same type-7 quantiles at
alpha/2 and 1-alpha/2, the same fine-cell centres and scatters, and actual-count
weights. Check: max |c_j(SIIE-HK) - c_hk(DSIIE)| and max |Omega_j(SIIE-HK) -
Omega_hk(DSIIE)| over all cells, required <= 1e-12.

## Reuse check

The archived v8 SIIE and DSIIE values are reused only if the refitted r_ave agree
with them to <= 1e-10 in every replication. The diagnostic table is computed from
the refitted values in all cases (they are identical when the check passes). The
same comparison is reported for SIR, SAVE, pHd, DR and SIME.

## Metric and summaries

Target dimension d = 1, so r_ave equals the single canonical correlation and
r_min is not reported. Per cell and setting: R, failures, mean r_ave and its
Monte Carlo standard error sd/sqrt(R). Paired differences over the same samples:
DSIIE - SIIE (HK slices) and DSIIE - SIIE (H slices) and SIIE (HK slices) - SIIE
(H slices): mean, half-width 1.96 sd/sqrt(R_pairs), number of replications with
DSIIE larger. Values are reported to three decimals.

## Failure handling

Every fit is wrapped in `safe_fit`; a failure is recorded with its message and
excluded only from the pairs it belongs to; no retries, no replacement seeds.
Failure counts are reported in the table.

## Interpretation rule (fixed in advance)

An aggregation benefit is claimed for a cell only if the 95% Monte Carlo interval
for DSIIE - SIIE (HK slices) lies entirely above zero; an interval below zero is
reported as a loss; otherwise as no detectable difference. All three cells are
reported whatever the outcome. A gain over SIIE settings is not a gain over the
other SDR methods.
